# Tourism Web Portal

A dynamic tourism web application showcasing 10+ tourist locations with images, descriptions, and a responsive user-friendly interface. Built using Java JSP, Servlets, JDBC, and MySQL.

📌 What This Project Does

This Tourism Web Portal allows users to:
- Browse multiple tourist locations
- View detailed information about each location
- Explore high–quality images for every place
- Navigate seamlessly across pages on all devices

The goal is to make travel research **simple, attractive, and informative** for users.

💡 Why This Project Was Built

Tourists often find scattered and incomplete information about destinations.  
This system solves that by offering:
- Complete details about popular travel spots in one portal
- High-quality images to understand the location visually
- Easy navigation and clean URLs for better user experience

It can be used as:
- A tourism information system
- A city travel guide
- A base for a larger online booking platform

🛠 Tech Stack
- Language: Java  
- Server-Side: JSP, Servlets  
- Database: MySQL (JDBC connectivity)  
- Frontend: HTML, CSS, Bootstrap  
- Session Management: For image caching and fast access  
- Server: Apache Tomcat
